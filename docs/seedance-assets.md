# Seedance 私域素材库

素材组及素材的接口均校验当前登录用户的归属。上传的媒体保存在阿里云 OSS，预览使用短期签名链接，审核进入终态不会自动删除对象。

## 存储与账号绑定

新上传的对象记录固定保存 Region、Endpoint、Bucket 与 ObjectKey；预览和清理按该位置访问，凭证仍来自系统设置。上传失败后的补偿复用上传开始时的客户端，避免配置切换后清理错误的 Bucket。已有对象没有位置快照时沿用当前存储配置，因此仍禁止在存在 OSS 素材时修改存储位置。

新建素材组从渠道可用密钥中选择一个账号，仅保存密钥的 SHA-256 摘要。上传、查询和删除沿用该绑定，密钥列表重排不会切换账号；绑定密钥被禁用或移除时返回错误，不会静默改用其他账号。

## 删除与并发

删除先持久化 `Deleting` 状态，确认上游删除成功后才回收 OSS 和本地映射。上游成功阶段会记录完成时间；存储或数据库失败时保留剩余记录，再次删除可继续清理。只有上游明确返回资源不存在才视为幂等成功，其他业务失败不会被 HTTP 200 掩盖。

素材最终落库与分组删除共用数据库锁。在途上传完成后发现分组已删除或正在删除，会拒绝入库并补偿上游资源和 OSS 对象。外部网络请求不持有数据库行锁。

## 列表接口

`GET /api/user/seedance/assets` 支持 `group_id`、`p`、`page_size`（1 至 100）、`search`、`asset_type`（Image/Video/Audio）与 `status`（Processing/Active/Failed）。搜索和筛选先于分页执行。

响应保留 `data` 素材数组，并返回 `total`、`page`、`page_size`、`has_pending`。客户端可据此浏览全部素材，并在当前分组有审核任务时持续获取状态。手动刷新返回数据库中的完整最新记录，前端只替换对应素材，不重新加载其他预览。

## 上游请求

直连和代理统一使用请求级 30 秒截止时间，覆盖响应体读取。上游业务错误在公共调用入口校验，兼容代理的 `code`/`success` 错误与方舟的 `ResponseMetadata.Error`。
